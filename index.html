Projects

Jordan Navigation System

Web version coming soon

A console app that plans trips between Jordanian cities.

Problem: When you have several places to visit, it's hard to know which order to visit them in.

Solution: It combines Dijkstra's algorithm to find the shortest path between cities, with a greedy approach that always visits the nearest stop next, then shows each leg of the trip and the total distance.

  • C++
  • Dijkstra's algorithm
  • Greedy algorithm

School Management System

In progress

My graduation project: a bilingual (Arabic/English) system for managing a school.

Problem: Schools often manage students, grades, and attendance across paper records and scattered files, which makes tracking hard and error-prone.

Solution: One system with role-based access for admins, teachers, students, and parents, covering student records, classes, grades, and attendance. I'm building the backend API.

  • ASP.NET Core Web API
