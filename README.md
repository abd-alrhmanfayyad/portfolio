# Abd Alrhman Fayyad – Portfolio Website

My personal portfolio website, built as part of my training at Orange Coding Academy.
It introduces who I am, the skills I work with, my projects, and my learning journey.

**Live website:** https://abd-alrhmanfayyad.github.io/portfolio/

## Technologies used

- HTML5 (semantic elements)
- CSS3 (Flexbox, Grid, CSS variables, media queries)
- Git and GitHub Pages
- JavaScript (dark mode toggle)
## Features

- Sticky navigation bar with smooth scrolling
- Mobile-first, fully responsive layout
- Project cards with hover effects
- Learning journey timeline
- Downloadable CV
- Dark/Light mode toggle (saved in the browser)
